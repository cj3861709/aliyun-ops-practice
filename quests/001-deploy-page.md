## 我会给你什么

**不给命令，只给方向。** 你可以自己查，也可以问我。

**允许用的命令**（都是安全的）：

```bash
mkdir        建目录
cat > 文件    写文件内容（Ctrl+D 结束输入）
ls -la       看文件权限
nginx -t     校验配置
systemctl reload nginx    重新加载
curl         访问测试
ss -tlnp     看端口监听
sudo -u nginx test -r 文件    验证 nginx 能否读文件
```

## 你会学到什么

这个热身任务里藏着这几个必考知识点：

1. **改配置前要备份** —— 不然改坏了怎么办？
2. **`nginx -t` 必须先跑** —— 语法错了 reload 会失败
3. **权限** —— nginx 以 `nginx` 用户运行，不是 root
4. **`reload` 而不是 `restart`** —— 前者不中断服务

**这些我不主动讲，你自己踩到了再问我，或者自己查。**
